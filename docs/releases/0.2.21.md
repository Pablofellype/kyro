# Kyro 0.2.21: WhatsApp por usuário e Robô de Aderências no VPS

Esta versão separa o WhatsApp de cada conta e permite que o Robô de Aderências continue funcionando no VPS mesmo quando o computador do usuário estiver desligado.

## Novidades

- O administrador pode liberar ou remover o acesso ao Robô de Aderências individualmente para cada usuário.
- Usuários com essa permissão podem usar o robô pelo navegador ou pelo aplicativo desktop, com o WhatsApp conectado na própria sessão remota do VPS.
- Usuários sem a permissão continuam usando o gateway local do aplicativo desktop, sem depender do VPS.
- O aplicativo desktop continua disponível para todos os usuários: a conexão remota é usada somente por quem tem acesso ao robô.
- O navegador usa o WhatsApp remoto sem exigir instalação do gateway no computador.
- Planilhas, configurações e agendamentos do Robô de Aderências ficam separados por usuário.

## Correções

- Cada sessão do WhatsApp agora usa um dispositivo próprio no gateway, evitando que uma conta substitua a sessão de outra.
- Webhooks são encaminhados para o usuário correto usando o identificador da sessão e o JID como fallback.
- A conexão de um usuário não depende mais de o WhatsApp do administrador estar ligado.
- O agendador do VPS verifica as rotinas de todas as contas autorizadas e recupera horários dentro da janela configurada.
- A tela de conexões mostra o modo correto: gateway local para usuários comuns e WhatsApp remoto para usuários autorizados no robô.
