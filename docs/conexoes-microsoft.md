# Conexões Microsoft removidas

Outlook / Microsoft 365, Microsoft Teams e Microsoft Planner foram retirados do catálogo **Conexões** porque dependiam de um registro de aplicativo no Microsoft Entra. O Kyro também desconsidera essas conexões ao carregar configurações de versões anteriores.

O Power BI em **Empresa → Power BI** usa a autenticação do próprio relatório. **Agendas por link** importa calendários por endereço ICS.
